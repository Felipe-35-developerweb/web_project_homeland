# De Pátria para Pátria

## Descrição

“De Pátria para Pátria” é uma página responsiva inspirada nas histórias, cidades e países de origem de diferentes pessoas. O projeto foi desenvolvido a partir de um layout no Figma e se adapta para telas desktop, tablet e celular.

## Tecnologias utilizadas

- HTML5 semântico
- CSS3
- Metodologia BEM para nomear classes
- Flexbox
- Media queries para responsividade
- Fonte Inter carregada localmente
- Git e GitHub para versionamento do código

## Planos de melhoria

- Criar um logotipo em SVG mais detalhado para aproximar ainda mais a página do layout original.
- Adicionar novas histórias e imagens de diferentes cidades.
- Melhorar a acessibilidade com revisões adicionais de contraste e navegação por teclado.
